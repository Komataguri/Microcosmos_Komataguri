# KOMA TRANSLATE

Статическая библиотека и читалка переводов. Для работы сайта не нужны база данных, серверное приложение или установка пакетов.

## Локальный запуск

Откройте командную строку в корневой папке проекта и выполните:

```bash
python -m http.server 8000
```

После этого откройте в браузере:

```text
http://localhost:8000
```

Открывать `index.html` двойным щелчком нельзя. Браузер блокирует загрузку глав через `fetch` при работе без локального сервера.

## Структура

- `index.html` — библиотека с каруселью книг
- `book.html` — сведения о книге, оглавление и читалка
- `privacy.html` — политика конфиденциальности
- `scripts/books.js` — единый каталог книг и будущих проектов
- `scripts/home.js` — построение карточек и управление главной страницей
- `scripts/carousel.js` — прокрутка карусели
- `scripts/book.js` — загрузка глав, навигация и сохранение прогресса
- `styles/` — оформление страниц
- `chapters/BookN/` — главы и оглавление отдельной книги
- `images/` — обложки

## Добавление глав

1. Поместите Markdown-файлы в нужную папку `chapters/BookN`.
2. Пересоздайте оглавление:

```bash
python chapters/generate_chapters.py chapters/BookN
```

3. Проверьте книгу через локальный сервер.

Генератор берёт заголовок из первой строки Markdown-файла. Первая строка должна начинаться с `#`.

## Подключение будущей книги

1. Найдите нужный номер в массиве `FUTURE_BOOK_IDS` в `scripts/books.js` и удалите его из массива.
2. Добавьте объект `BookN` в основной каталог по образцу уже подключённых книг.
3. Добавьте обложку `images/book-cover_N.jpg`.
4. Создайте папку `chapters/BookN` с главами и `chapters.json`.

До подключения карточка остаётся в карусели с подписью «Скоро» и не открывает пустую страницу.

## Прогресс чтения

Для каждой книги отдельно сохраняются:

- последняя открытая глава
- позиция внутри главы
- тема оформления
- размер текста
- до 20 недавно открытых глав

Эти данные находятся только в локальном хранилище браузера пользователя.

## Ссылки на главы

При открытии главы адрес страницы обновляется автоматически. Такой адрес можно сохранить в закладки или отправить другому читателю. Кнопки браузера «Назад» и «Вперёд» поддерживаются.

## Публикация

Перед публикацией проверьте структуру сайта:

```bash
python scripts/validate_site.py
```

После успешной проверки подготовьте статическую версию:

```bash
python scripts/build_site.py
```

Готовые файлы появятся в папке `dist`. При размещении через Sites соединение HTTPS и SSL-сертификат настраиваются сервисом автоматически.

## Конфиденциальность

Перед добавлением регистрации, комментариев, форм, аналитики или платёжных функций необходимо обновить `privacy.html`.
